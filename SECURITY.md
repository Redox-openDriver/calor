# Безопасность

Об уязвимости сообщай не в открытом issue, а через [Security → Report a vulnerability](https://github.com/Redox-openDriver/calor/security/advisories/new)
на GitHub: сообщение увидят только сопровождающие. Опиши, что нужно сделать, чтобы воспроизвести, и что из этого
следует.

Библиотека только считает: устройств, файлов и сети она не открывает, `unsafe` в ней нет. Показания датчиков и
дневник охлаждения ей отдаёт драйвер; невозможные значения (не числа, бесконечности, даты из будущего) отбрасываются,
а не ломают дневник.
