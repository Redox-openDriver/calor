# calor

Тепло ноутбука без привязки к устройству и ОС: драйвер даёт показания датчиков и мощность процессора, `calor`
решает, что из них следует.
Используется драйвером [lenthm-21kk](https://github.com/Redox-openDriver/lenthm-21kk) и годится для любого другого.

## Что умеет
| модуль | что делает |
|---|---|
| `reading` | `Reading` — одно показание: датчики с местом (процессор, графика, плата, накопитель, беспроводная сеть, батарея) и критической температурой, если она известна, мощность процессора, работает ли вентилятор |
| `watch` | `Watch` — что сказать человеку: процессор горячий не на мгновение, а дольше заданного; снова остыл; датчик подошёл к своей критической температуре; охлаждение стало заметно хуже |
| `cooling` | здоровье охлаждения: при ровной нагрузке запоминает, насколько процессор теплее остального ноутбука при той же мощности, и сравнивает последнюю неделю с первыми двумя неделями. Если охлаждение с месяцами хуже (пыль в радиаторе, высохшая термопаста), это видно в процентах раньше, чем ноутбук начнёт тормозить |

Единицы: температура в тысячных долях градуса Цельсия, мощность в мВт, время в микросекундах монотонных часов. Без
`std`, только `alloc`.
